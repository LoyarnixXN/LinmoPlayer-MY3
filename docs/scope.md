# 当前范围与输入拆分

## 本次用户请求（当前优先级最高）

- 项目从 0 开始立项，需要补齐文档和基础架构；
- 先保证音乐播放器本体具备后续插件扩展的位置；
- 当前阶段不要开发插件；
- 界面设计遵循 Material You / Material 3。

## `ax.txt` 中保留为项目背景的内容

- 移动端优先、后续多平台；
- 主程序作为播放器壳，负责 UI、播放、本地数据、生命周期和聚合；
- 统一歌曲/歌单模型；
- 插件失败隔离、歌单聚合、按需/定时同步的方向；
- 插件使用独立契约，主程序不绑定具体平台实现；
- 仅供个人学习研究并遵守数据来源平台规则。

## 根据当前请求明确延期的内容

以下内容虽出现在 `ax.txt` 的后续清单中，但本阶段不执行：

- 任何具体音源插件；
- 任何第三方平台 API 地址、签名、解析和登录流程；
- 第三方平台播放地址获取与歌词接口；
- 远程插件下载、安装、更新、市场；
- 移动端不可信 JavaScript 的实际动态执行。

## 本阶段交付

- `packages/core`：平台无关的统一模型、播放端口、插件契约、注册表、加载边界和歌单聚合器；
- `apps/mobile`：Material 3 风格的移动端 UI 基线，包含首页、歌库、插件空状态、设置和迷你播放器；
- `docs/`：架构、契约、设计系统、范围拆分和路线图。
