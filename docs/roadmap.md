# 项目路线图

## Phase 0 — 当前基线

- [x] 项目文档与目录结构
- [x] 统一歌曲/歌单模型
- [x] 插件契约、注册表和异常隔离抽象
- [x] Material 3 移动端 UI 基线
- [ ] 真机音频适配器

## Phase 1 — 本体可用

- [x] 本地音频文件导入与基础播放
- [ ] 播放队列、进度记忆和后台播放
- [ ] SQLite/设备存储适配器
- [ ] 歌单创建、编辑、排序与离线查看
- [ ] Now Playing、歌词容器和播放通知

## Phase 2 — 插件管理与运行时安全

- [x] 插件 manifest 校验
- [ ] 权限声明与用户授权
- [ ] 移动端 JS 沙箱评估
- [ ] 包完整性、版本兼容和回滚
- [x] 插件管理页面的导入/启用/停用/卸载流程

## Phase 3 — 第一个外部音源插件

只有 Phase 2 通过安全评审后，才开始单独实现第一个插件。插件放在独立仓库或外部目录，不把平台 API 代码带入宿主。

## Phase 4 — 多平台

- [ ] 桌面壳适配
- [ ] 复用 `packages/core`
- [ ] 跨端播放队列与本地数据迁移
